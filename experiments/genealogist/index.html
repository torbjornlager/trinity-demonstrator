    Under the hood Small Prolog rules. An independent browser UI.
    The diagram reads relationship(Role, Parent, Child) from the same session used by your queries. The form calls add_relationship/3 and remove_relationship/3. Prolog rejects self-parenting and cycles; no family reasoning is implemented in JavaScript.
    Queries return one answer at a time. Next resumes alternatives; Stop discards them. The diagram refreshes once a query finishes or is stopped. You can also query or update facts directly; a raw query can bypass the form’s validation.
    Changes live in this page’s Worker session and disappear on reload or closure. Save Prolog downloads the current facts with the rules. Other tabs have independent families. There is no server-side database or automatic storage.
