WebSocket API: actor messaging

This page uses the current spawn and send commands. It spawns a browser-owned actor that turns msg(Term) into terminal output with writeln(Term), subscribes that actor to the node-resident pubsub_service, and then lets you publish Prolog terms into the service. The actor obtains its own qualified pid with self/1; the browser sends commands only to the actor it owns. A node must advertise pubsub_service in /node_info to run this example.
