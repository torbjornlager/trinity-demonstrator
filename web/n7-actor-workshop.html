N7 ACTOR workshop

Try independent actors, selective receive, monitors and interactive input in the ECLiPSe CLP shell. The results appear in the terminal beside this page.

Counter actors · Mailbox ordering · Prompted updates · Actor exit · Actor names

Run two independent counters

Load the program, then start the counters. Each actor keeps its own total in a recursive argument. The shell remembers their PIDs by name.

:- dynamic workshop_counter/2.

counter_loop(Total) :-
    receive({
        add(From, Name, Amount) ->
            Next is Total + Amount,
            From ! total(Name, Next),
            counter_loop(Next)
    ;   stop -> true
    }).

start_counter(Name) :-
    ( workshop_counter(Name, _) -> true
    ; spawn(counter_loop(0), Pid),
      assertz(workshop_counter(Name, Pid))
    ).

send_add(Name, Amount) :-
    once(workshop_counter(Name, Pid)),
    self(Me),
    Pid ! add(Me, Name, Amount).

add_to(Name, Amount, Total) :-
    send_add(Name, Amount),
    receive({total(Name, Total) -> true}).

two_updates(Red, Blue) :-
    send_add(red, 2),
    send_add(blue, 5),
    receive({total(blue, Blue) -> true}),
    receive({total(red, Red) -> true}).

prompt_add(Name, Total) :-
    input('Amount to add (an integer)', Amount),
    integer(Amount),
    add_to(Name, Amount, Total).

stop_counters :-
    ( workshop_counter(Name, Pid) ->
        Pid ! stop,
        retractall(workshop_counter(Name, Pid)),
        stop_counters
    ; true
    ).
?- start_counter(red), start_counter(blue).
?- add_to(red, 3, Red).

Try the same call twice. Red starts at 3 and reaches 6. Blue is still at 0.

Receive replies in the order you choose

?- two_updates(Red, Blue).

The shell asks red first but waits for blue first. A red reply that arrives early stays in the mailbox for the second receive.

Drive an actor from a terminal prompt

?- prompt_add(red, Total).

Enter an integer such as 7. at the terminal prompt. The loaded predicate forwards your number to the red actor and returns its new total.

Observe a worker exit and clean up

?- spawn(exit(workshop_done), Pid, [monitor(true)]),
   receive({down(Pid, _, Reason) -> true}).

The monitor delivers a down message with reason workshop_done.

?- stop_counters.

Start them again to begin with empty totals.

Send to an actor by name

?- self(Me),
   spawn(receive({ping(From) -> From ! pong}, [timeout(5)]), Pid),
   register(workshop_ping, Pid),
   whereis(workshop_ping, Found), Found == Pid,
   monitor(workshop_ping, Ref),
   workshop_ping ! ping(Me),
   receive({pong -> true}, [timeout(2), on_timeout(fail)]),
   receive({down(Pid, Ref, true) -> true}, [timeout(2), on_timeout(fail)]),
   whereis(workshop_ping, After), After == undefined.

The name is shared by owner sessions on this node. The worker replies once and exits. When the monitor reports its exit, the name is free again. Use unregister(Name) to release a name while its actor keeps running.
