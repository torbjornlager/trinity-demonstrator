Familiar Prolog

Begin once more with the query used in the ACTOR and ISOTOPE tutorials:

?- append(Xs,Ys,[a,b,c]).

The answers are the same. What changes is the execution contract: asking for another answer means another self-contained stateless call rather than resuming a private toplevel session.

The stateless boundary

Every N1 request carries the goal, any temporary source text and the paging options needed for that computation. When the response is returned or the time limit is reached, no client-visible execution context remains.

The Examples drawer makes the boundary visible. Actor programs and SXML statecharts are struck out as they were on N2; on N1, examples that need a persistent session, editor loading, I/O or database updates are struck out as well.

What is unavailable

No interactive I/O

There is no ongoing conversation to receive output or answer an input prompt, so N1 rejects I/O goals such as:

?- writeln(hello).

No dynamic session database

A database update would have no private session in which to survive. Both assertion and retraction fall outside the profile:

?- assertz(saved(isobase)).

?- retract(saved(X)).

Timeout instead of Abort

Start this non-terminating goal and observe that the workbench has no Abort button for N1:

?- repeat, fail.

A stateless HTTP call has no separate control channel through which the client can address and abort the running computation. N1 terminates it at the server-enforced request timeout and reports the timeout as the result.

When to choose ISOBASE

ISOBASE's main advantages are:

  • a small, self-contained request/response contract;
  • no client session state to retain or recover;
  • straightforward replay, caching and load balancing; and
  • clear server-enforced time and resource bounds.

It is a good fit for search, validation, transformation, inference and other function-like services whose result depends entirely on the request and shared read-only knowledge.

The price is deliberate: no private state between calls, interactive I/O, client Abort, independent actors or push communication. When one of those is essential, use ISOTOPE or ACTOR. When it is not, ISOBASE is the smallest and clearest Web Prolog contract.
