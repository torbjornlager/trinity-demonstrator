# Browser actor transport

The browser transport contract is maintained with its implementation in
[swi-wasm-node](https://github.com/torbjornlager/swi-wasm-node/blob/v0.1.0/docs/browser_actor_transport.md).
The demonstrator consumes the exact revision in
[dependencies/swi-wasm-node.json](../dependencies/swi-wasm-node.json).
See the [shared language manual](../web/manual.html) for the common API.
